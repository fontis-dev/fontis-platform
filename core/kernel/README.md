# Kernel Configuration

This directory contains reference kernel configuration fragments and build
documentation for the Fontis Device Linux kernel.

Kernel config fragments live in:
    core/meta-fontis/recipes-kernel/linux/linux-fontis/*.cfg

The kernel recipe is:
    core/meta-fontis/recipes-kernel/linux/linux-fontis.bb

This directory is for developer reference and documentation. The Yocto layer
in `core/meta-fontis/` is the source of truth for kernel configuration.
